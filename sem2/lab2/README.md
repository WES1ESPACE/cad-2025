## Цель

Сделать ToDo-список на Spring MVC: модель, контроллер, страница на Thymeleaf.

## Что сделала

По примеру из методички:
- `Task`
- `TaskRepository` / `TaskService`
- `TaskController` (`/`, `/addTask`, `/deleteTask/{id}`, `/updateTask/{id}`)
- `templates/index.html`

Из доп. заданий взяла категории (Учеба / Личные дела / Работа) и подтверждение перед удалением. Страницу чуть подправила, чтобы было удобнее смотреть список.

## Запуск
