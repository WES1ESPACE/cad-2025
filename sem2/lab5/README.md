**Студентка:** Севрюкова Валерия Сергеевна

## Цель

Сделать REST для задач и простой Swing-клиент.

## Структура

- `server` — Spring Boot (как в lab4) + `GET/POST/DELETE /api`
- `client` — `LoginForm` и `TaskManagerForm`

## Что сделала

На сервере Basic Auth (как в методичке).  
Клиент логинится, забирает список с `/api`, умеет добавить/удалить задачу и поменять сортировку.  
В списке ещё показываю category и priority из БД (из доп. заданий).

## Запуск

Сначала сервер:

```text
cd sem2/lab5/server
mvn spring-boot:run
```

Потом клиент:

```text
cd sem2/lab5/client
mvn -q compile exec:java
```

Логин/пароль: `user` / `password` (или moderator, если надо удалять).

## Вывод

Клиент нормально ходит на сервер. Удаление без роли moderator сервер не даёт — это ожидаемо.
